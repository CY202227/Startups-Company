# 《初创公司》(Startups) 规则说明（面向当前 UI）

该版本是“能直接对应到页面按钮和状态提示”的中文规则说明。  
目标是解决两类问题：  
1) 原文术语与页面文案不一致；2) 规则过于简短导致上手慢。

> 推荐阅读路径：先看“3 分钟上手流程”，再看“反垄断规则”和“结算细则”。

## 你在页面上会看到什么

### 页面词汇与规则词汇对照

- 页面标题里的 **市场**：公开区域，公开摆放的是可以拿的公司卡。
- 页面里的 **反垄断持有人**：页面“公司反垄断持有人”列表中显示的玩家，即该公司反垄断筹码归属者。
- 页面按钮 **拿牌/出牌**：分别对应回合的两个阶段：
  - `Take` 阶段（拿牌）：`从牌堆` 或 `从市场`。
  - `Play` 阶段（出牌）：`打到个人区域` 或 `打到市场`。
- 计分中的 **翻牌**：UI 的 `flipped` 指结算时获得的 3 面筹码数（每枚按 3 分计）。

### 游戏目标（简化）

最终得分高者胜。  
核心竞争不是“谁拿牌更多”，而是谁在结算时能从“控盘公司”上赚取最多现金。

## 一、初始化

- 玩家数：3~7 人。
- 初始现金：每人 10 枚 1 面筹码。
- 初始手牌：每人 3 张。
- 公司牌总数固定为 45 张，6 家公司：
  - EMT（8）
  - Flaming Soft（8）
  - Hippo Powertech（7）
  - Bowwow Games（7）
  - Giraffe Beer（5）
  - Elephant Mars Travel（10）
- 牌堆洗牌后丢弃 5 张，剩余进入抽牌堆。

## 二、每回合流程（你必须执行）

每个玩家每回合有两步，顺序固定，不可交换：

1. 拿牌（Take）
2. 出牌（Play）

### 1）拿牌阶段（Take）

- `从牌堆`：  
  - 需要付费：市场上每张牌都要付 1 金币；  
  - 但如果这张市场牌属于你当前持有反垄断的公司，则这张牌不收 1 金币。  
  - 例如市场有 5 张牌，你在其中持有 2 家公司的反垄断，那么你本次从牌堆拿牌花费为 3 金币。
- `从市场`：  
  - 不能拿自己持有反垄断的公司牌。
  - 市场牌有附加金币（被拿下会立即加到你手上现金）。

### 2）出牌阶段（Play）

- 将手牌打到个人区域（你的持仓）或打到市场（成为公开牌）。
- 如果你本回合第一步是“从市场拿到某家公司牌”，本回合第二步不能把同一公司牌立刻再打回市场。
- 出牌后回合结束，轮到下一位玩家。

### 新手完整回合示例

假设现在轮到 P0，市场里有 3 张牌：

- EMT，+0 金币，可取。
- Giraffe Beer，+2 金币，可取。
- Flaming Soft，+1 金币，但 P0 正持有 Flaming Soft 的反垄断。

P0 在拿牌阶段有两个选择：

- 从牌堆抽牌：需要给市场牌放金币。因为 Flaming Soft 属于 P0
  反垄断公司，所以这张不收费；本次总花费为 2 金币。
- 从市场拿牌：可以拿 EMT 或 Giraffe Beer。若拿 Giraffe Beer，
  P0 会立刻获得该牌上的 2 金币；不能拿 Flaming Soft。

假设 P0 从市场拿了 Giraffe Beer，随后进入出牌阶段：

- P0 可以把手牌打到个人区域，增加自己的持仓。
- P0 也可以把手牌打到市场，留给后续玩家拿。
- 但如果 P0 手上还有另一张 Giraffe Beer，本回合不能把它立刻打回市场。

出牌完成后，系统重新计算反垄断持有人，并轮到下一位玩家。

## 三、反垄断持有人（Anti-Monopoly）规则

每家公司有 1 个“反垄断持有人（筹码）”，决定谁拿该公司市场牌的阻止权与抽牌减免条件。

- 计算规则：看所有玩家该公司在个人区域的持仓数量。
- 持仓最高且唯一最高者持有该公司的反垄断持有人。
- 若并列最高，通常会出现“无持有人”；但若旧持有人仍然与最高值并列，页面规则会保留旧持有人直到出现新唯一领先者。
- 当某公司出现了新的唯一最高者时，立即转移到新持有人。
- UI 的“不可取（反垄断）”状态卡就是当前持有该公司反垄断的玩家禁止直接拿市场该公司牌的提示。

## 四、结算（游戏结束）

### 触发方式

- 某位玩家在 `Take` 阶段从牌堆拿到最后一张牌，并完成本回合 2 步后，立刻进入结算。

### 结算步骤

- 将该玩家手牌公开，合并进个人持仓后再进行公司逐家清算。
- 对每个公司：
  - 若存在唯一最大持仓者，该玩家向每个持仓更少的玩家收取对方“该公司股份数”枚 1 面筹码。
  - 无唯一最大者（持平）时，不发生结算。
- 结算时现金不足时：
  - 尽量支付可支付的金额；
  - 未支付部分记录为扣分（`penalty`），以保证回放/评分可持续确定。
- 得分公式：
  - `最终分 = 现有1面现金 + 翻牌数 * 3 + penalty`
- 平局：没有胜负（显示“平局”）。

## 五、你可直接对照的 UI 小抄（建议新手先看）

- **“抽牌堆剩余”**：剩余抽牌数。  
- **“市场”**：可见牌；点击按钮即可拿。
- **“可取/不可取（反垄断）”**：反映是否允许拿牌。
- **“公司反垄断持有人”**：当前每家公司占优者。
- **“牌桌详情”**：你和对手各自现金与持仓。
- **“结算结果”**：每人得分及胜负显示。

## 六、常见疑问

### 为什么有时明明有现金却点不动“从牌堆”？

因为 `Take from deck` 会按市场牌数量计算花费，可能会大于当前现金。

### 为什么市场牌会贴“+x”？

这是该牌当前已累积的市场附加金币。你拿下后会直接加到你现金中。

### 为什么明明牌很多，仍然结束？

游戏结束触发于“抽牌堆最后一张被拿走且该回合完成出牌”，不是看市场里牌有多少。

## 七、与实现参数映射（便于开发/测试理解）

- 两阶段：`TAKE` / `PLAY` / `FINISHED`。
- 关键动作：`TAKE_FROM_DECK`、`TAKE_FROM_MARKET`、`PLAY_TO_PORTFOLIO`、`PLAY_TO_MARKET`。
- 结算分支在代码里有 `penalty` 兜底，以避免支付不足导致状态不可计算。
- 规则文本强调的是“可执行版本”，和页面交互行为保持一致。
